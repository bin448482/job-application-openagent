# app/adapters 目录指南

## 一、目录用途

实现 `app/ports/` 声明的具体通道。当前只有 M0 的 ADB 只读探针；fixture 输入由 CLI 读取，不属于设备适配器。

## 二、当前文件与子目录

- `__init__.py`：声明适配器包。
- `adb/`：真实 ADB 探针实现；见 `adb/AGENTS.md`。

## 三、边界

- 适配器只返回领域对象或携带安全原因码的失败，不写业务库、不改调度、不决定策略档位、不重试。
- 真实 ADB 适配器只能由显式 `--device --serial` 触发；fixture 模式不得导入或调用其探针。
- 不输出真实序列号、窗口原文、异常命令参数或绝对路径。
- 不预建 SQLite、模型桥、BOSS 页面、猎聘等未实现适配器目录。

## 四、维护要求

1. 新增适配器目录时同时创建 `AGENTS.md` 与只含 `@AGENTS.md` 的 `CLAUDE.md`，并更新本索引与根 `AGENTS.md`。
2. 选择器、命令参数和解析规则必须带合成夹具或 mock 测试；不得把真实设备数据写入公开材料。
3. 每个源文件顶部写用途，每个函数/方法写 docstring。

## 五、已知限制

- 只有 M0 设备清单、解锁与前台组件读取。
- 真实设备输出格式、机型差异与时序未验证。
