## 1 测试层、状态与版本门槛

| 层代号 | 准备方式与用途 | 当前能否执行 |
|---|---|---|
| E0 现有自检 | 原样运行 npm test；保留现有 24 例及反例 | 可以；无需安装、凭据、设备或网络 |
| F 确定性离线 | 独立人工编写的纯合成 profile/XML/DB/时钟/故障序列，模拟设备和桥 | 不能；未来 M0 起逐步实现，本文仅设计 |
| T 受控设备 | 获同意后使用合规且可用的测试协作条件，明确参与者、动作、资料及撤销条件 | 不能；没有假设现成测试服、测试账号或造消息工具 |
| O 机会性观察 | 正常账号自然出现的信号，只读列表；额外同意才能进入会话 | 不能；没有本轮设备确认，随机触发不能保证 |
| W 真实单条写入 | 每一动作单独确认，实际前后证据、人工出口 | 不能；M5 以后并满足前级门槛 |

T 只有在实际具备合规条件且参与者自愿时才建立；禁止邀请真实 HR 配合测试、自动发送自导自演消息、修改真实服务器未读标记。把会话标为未读不是新入站，反复打开会话不是准备夹具的手段。缺 T 条件记 BLOCKED，使用 F 覆盖逻辑，O 补版本现场；两者不能替代真实 E2E。[G；V §6；P §8]

执行前登记代码提交、契约版本、fixture/独立标签版本、profile 版本与标定来源、策略包版本；设备侧只在本机登记应用/系统/分辨率/字体/布局版本。换版本、导航、输入法或版式变化使旧定位快照失效，重新获取当前证据，不挪用历史坐标。[A §5.3–5.4；V V1/V3/V4]

每条记录同时含 `execution=planned/executed`、`layer` 与 `result`：

| 结果 | 使用条件 | 对门禁的意义 |
|---|---|---|
| PASS | 前置满足、事件实际触发、独立预期全部吻合且证据齐全 | 只通过该层、该版本、该变体 |
| FAIL | 有效环境中，被测行为违反已定契约 | 产品缺陷，阻断受影响能力 |
| BLOCKED | 缺实现、授权、工具或合规测试条件，无法开始 | 环境/准备阻塞，不能算产品失败或通过 |
| INCONCLUSIVE | 已开始但竞争、版本未知或证据丢失使结果无法裁决 | 补测，不进入通过分子 |
| NOT_COVERED（未覆盖） | 有界窗口中未触发目标事件，或本次未计划执行该分支 | 不声称验证过；进入补测队列 |

预期安全停止本身可在 F 中 PASS；例如注入未知后确实停止。但 O 中“没有阳性”不使阳性识别场景 PASS；同一轮可有“未授权未点击”PASS 与“未读阳性”NOT_COVERED，须分成两条记录。本文的文档审查完成不改变业务场景的 planned 状态。

## 2 公共规程与独立判据

### 2.1 离线准备与重放规程 F0

1. 先读场景的来源与期望；人工写标签，再写输入和参考响应，标签不由被测输出反推。使用“合成联系人甲/合成机构甲/合成岗位甲”等假身份，不从真实聊天改写夹具。
2. M2 按 P M2 现有设计形状准备 manifest、profile、XML、独立 expected；输入只引用输入文件，expected 不进入传感器。schema 的所有键/额外键/路径规则遵守 P M2，脚本调度信息另作测试驱动的 sidecar，不混进生产 manifest。
3. 数据库从空的临时合成库初始化，owner/PID/host、时钟与设备状态全部注入；禁读本机运行库、真实 PID、设备、根 config.json 或环境配置。禁止测试驱动回退至真实适配器；离线设备/网络调用计数必须为 0。
4. 按指定虚拟时间推进事件；运行一次，检查输出、事务、调用序列及独立标签；从干净合成初态重放相同事件应有同等业务结果。幂等测试则明确保留第一次数据库，不清库。
5. 记录场景与变体、输入/标签版本、实际序列、差异、耗时/调用计数、停止点；首次不符即 FAIL，保留合成差异后结束，不修改 expected 迁就实现。

标签分为 `truth_unread`、每源状态/理由、是否有可定位身份、覆盖范围、可领取候选、动作是否实际发生及其 effect；聚合 present 不等同于已读全消息。独立复核者应只看输入与契约先给标签，再看产品输出；如暂由同一编写者审查，标“作者自审”，不得声称独立测试人员验收。相同指纹不证明再次入站；读全后的消息身份与发现身份分开。[A §5.3、§6；P M2；C]

### 2.2 证据与停止公共规则 F1

F 证据为合成输入版本、独立 expected、调用 trace、前后表行/事件及断言差异；不是截图。T/O/W 的 XML、截图、DB、契约、原始响应仅放本机被忽略的 `data/` 或 `screenshots/` 子路径，运行前核对忽略状态，记录最小必要内容及保留期限。公开记录只含重新合成的元数据，不上传真实事件哈希、时间线、假名映射；哈希和假名仍可关联人，不能当匿名数据外发。[G；K §1、4、6、9；A §9]

若出现身份不唯一、未知现场、在途命令或 pending/unknown 动作，停止新任务，不靠重试掩盖。可证明动作前未执行才进入 not_performed；点击后证据缺失用 unknown，不改成未发。人工核对、重连、退出重入均是新轮次，重新说明动作并确认，旧未知锁不因取消、TTL 或换进程解除。[A §5.5、§6–7]

### 2.3 当前自检与未来命令

当前只运行 `npm test`（C，Node ≥22.22.0），检查断言/反例；不安装依赖、不跑模型或 smoke。未来 M0–M2 的验收入口如下，仅在对应代码与测试真实存在后运行，缺模块是 BLOCKED，运行 0 项不算 PASS：[P §4]

```text
python -m unittest tests.test_doctor
python -m app doctor --fixture tests/fixtures/doctor/ready.json
python -m unittest tests.test_store tests.test_migrations
python -m app store init --db data/runtime/m1-acceptance.sqlite3
python -m unittest tests.test_sensor tests.test_sensor_store
python -m app sense --fixture tests/fixtures/sensor/positive.json --db data/runtime/m2-acceptance.sqlite3
```

以上为未来合成路径，不在本次创建。M3–M8 尚无现成测试命令，下面以规程验收，不编造可运行入口。真实探针、只读采集和写入分开授权；M0 探针最多 10 秒，不包括消息 dump。[P M0、M3–M8]

## 5 随机未读的实机分支规程

### 5.1 本轮确认与有界窗口

所有以下动作都是未来规程，本轮不执行。测试负责人先填模板并取得本轮明确回答；授权编号与完整确认仅本机保存：

```text
测试轮次：<本机轮次>；目标：<场景ID与版本>。
拟做：<设备探针/读取当前列表/导航与滚动分别列出>；预计<秒数>，上限<秒数>。
是否独占：<是/否>；期间请勿手动或在另一终端读取目标会话。
```

## 9 五种动作、故障窗口、恢复与清理

### 9.2 每个不可逆动作必须交叉的故障窗口

以下 F-A 至 F-E 分别应用于 A01–A05（A06 也应用），独立记录如 `SC-A02/F-C`，不能只测文本就推论其它动作。

| 故障变体 | 注入顺序、判据 | 停止与恢复 |
|---|---|---|
| F-A 动作前失败 | 授权缺失/前置失败/确认前取消；oracle证明未点击任何可能写入控件 | not_performed+none，原因authorization_missing/precondition_failed/cancelled_before_action；现场未收敛仍暂停；新尝试先核对，不自动重发 |
| F-B pending后崩溃、未能证明未点击 | pending提交→中断，丢失是否发出命令证据 | pending残留保锁并人工核对，不能凭无返回降为not_sent |
| F-C 点击后断连/崩溃 | 模拟远端已执行但前后核验未回，或远端结果未知 | Evidence.unknown，reason=device_disconnected/executor_interrupted；blocked+隔离，执行次数最多1；不重放 |
| F-D 点击后核验不足 | 返回空/冲突/方向不明/删除锚点缺失 | unknown/result_unverified，不以Toast或确认框证明成功，不换会话继续 |
| F-E 已核验但本地提交失败 | 远端performed→事件/状态事务写入失败→重启尝试同动作键 | 数据回滚不能撤销远端动作；保留可对账pending锁，不执行第二次；重新对账后原子写结果，失败不得标done |

## 10 指标、分桶与发布门禁

### 10.1 指标报告

每个报告保留 numerator、denominator、excluded、unknown、暂停/未覆盖计数、版本、窗口与layer。F、T、O、W 独立汇总；E0/smoke/model 另列来源，不混到运行时指标。所有零分母填 `N/A (not_measured)`，不填0%、100%或“达标”。[A §10；P §1、M8]
