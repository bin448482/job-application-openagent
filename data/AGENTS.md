# data 目录指南

## 目录职责

本机运行产物预留目录，只提交目录说明。 全局工作规则见[根目录 AGENTS.md](../AGENTS.md)。

## 当前结构

- `evals/`：promptfoo 自动生成的本机状态及逐次 JSON 报告，被 Git 忽略；属于运行产物，排除指导文档覆盖。
- `AGENTS.md`：本目录职责、当前结构、接口、适用约束与维护要求。
- `CLAUDE.md`：仅含 `@AGENTS.md`，引用本目录指南。

## 入口与接口

evals/run.cjs 将 promptfoo 状态及逐次结果写入 data/evals，smoke 与 model 使用不同目录前缀。业务数据库、契约及日志接口仍待设计，不沿用旧 data/jobs.sqlite3 默认值。

## 适用约束

数据库、日志、契约、凭据和个人事实只留本机。遵守根 .gitignore 的 data/** 排除及双指导文件例外；不把未来自动生成目录纳入文档覆盖。 项目处于重新设计阶段，本次仅维护指导文档。

## 验证方式

从项目根执行 `npm run eval:smoke` 验证评测报告生成；`git check-ignore data/evals/` 检查运行产物排除。CLAUDE.md 只能包含单行 `@AGENTS.md`，可有末尾换行。不执行已清理业务模块的旧测试。

## 已知限制

评测产物不是业务执行、实际记忆持久化或设备验证结果；数据库和业务存储结构仍待设计。

## 同步维护要求

新增、删除、改名、移动文件或子目录，或职责、入口、接口、约束、测试命令、已知限制变化时，在同一变更中同步更新本指南；涉及其他目录时，同时更新对应指南和受影响父目录索引。不因占位说明创建空模块目录。
