# reviews 目录指南

## 一、目录用途

保存本目录资产的三轮作者自审记录。记录发现、修订、复验命令、计数、限制与剩余缺口；明确不是独立第三方审查、实机验收或产品通过证明。

## 二、文件清单

- `BOSS直聘_离线场景资产_三轮自审记录_20261124.md`：R1 覆盖与独立 oracle、R2 故障/安全/跨模块、R3 真实性/副作用/文档一致性，含协调端独立复现输入与我方修订复验。
- `AGENTS.md`：本文件。
- `CLAUDE.md`：只包含 `@AGENTS.md`。

## 三、维护要求

- 每次新增场景、变体、隔离逻辑或比较语义后补对应轮次发现与复验；不得把旧记录当新版本证据。
- 不声称独立审查；如由协调端复现，明确标注“协调端独立复现”，不得写成我方自审或第三方验收。
- 不写作者身份元数据、绝对路径、真实业务数据、凭据或设备标识。
- 报告与运行产物不写入本目录；本目录只存可复核的 Markdown 记录。
