## 第一轮：原始刺激独立性

发现：
1. `unrelated_change` 原用 `done.replace("岗位详情", ...)`，改的是目标子树内部，不是目标外 sibling。
2. `preexisting_done_unrelated_change` 缺失；只有 before 可用→after 目标不变外部变化的负控，不能替代“before 已 done、0 tap、after 未消费”的独立责任。
3. Toast 原是把目标按钮文字换成“已投递”的 TextView，不是真实 Toast；dialog 原是两个无 class 的按钮兄弟，没有独立对话框容器。
4. 控制输出只有 env 字符串常量，没有目标子树 canonical、目标外变化、Toast/Dialog 结构、读取次数/after 消费的独立 XML 解析事实。

修改：
- `unrelated_change` 改为：before 可用；after 目标子树 canonical 不变、目标外 sibling 变化；真实点击并消费 after。
- 新增 `preexisting_done_unrelated_change`：before/after 目标均已完成、目标外 sibling 变化；0 不可逆、after 未消费；单独记录。
- Toast 改为真实 `android.widget.Toast` 节点（目标仍无 done）；dialog 改为独立 `android.app.Dialog` 容器，含确认/取消孩子（目标仍无 done）；empty 保持空结果并断言 after 实际消费。
- `_xml_facts` 独立解析原始 XML，输出目标 canonical 摘要/相等、目标外文本变化、Toast/Dialog 结构、目标 after done。

验证：
- `--only SC-A06/A06_base` PASS，`--only SC-A06/A06_FD` PASS；facts 显示 preexisting_done after_consumed=False、target_unchanged=True；preexisting_done_unrelated_change external_changed=True、after_consumed=False；unrelated_change target_unchanged=True、external_changed=True、after_consumed=True；toast_present=True；dialog_container/controls_present=True。
